Guía rápida de ejes equivalentes

Idea central Convertir distintas cargas de tránsito pesado a un eje patrón de 8.2 t.
Variable de diseño EE acumulados en el carril de diseño durante el período de análisis.
Fórmula didáctica EE = IMDA pesado x FC x 365 x Fd x Fcarril x crecimiento.
Cómo explicarlo Más camiones, más sobrecarga o más años producen mayor consumo de vida.

En el Manual MTC 2014 el tránsito pesado se clasifica por rangos TP según repeticiones acumuladas de EE de 8.2 t en el carril de diseño.

Como presentarlo paso a paso

  1. Primero fija el trafico: IMDA, porcentaje de pesados y factor camion.
  2. Luego ajusta la estructura: espesores, coeficientes y CBR de subrasante.
  3. Presiona reproducir o mueve el tiempo para acumular ESAL con los anos.
  4. Observa la via: fisuras, ahuellamiento y baches aparecen cuando sube el dano.
  5. Compara las graficas: si el consumo llega a 100% o el PSI baja a 2.5, el pavimento falla.

Modelo usado

La demo estima ESAL por trafico pesado y factor camion. La capacidad se aproxima con una curva tipo AASHTO 1993 usando numero estructural, modulo resiliente estimado desde CBR, serviciabilidad, confiabilidad y drenaje. Para carreteras aplica criterios del Manual MTC; para vias urbanas aplica CE.010 del RNE. Es una herramienta didactica, no reemplaza un diseno definitivo.

ESAL = IMDA x %pesados x FC x 365 x Fd x Fcarril x crecimiento
