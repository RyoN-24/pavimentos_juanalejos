Flujo de uso

  1. Primero fija el trafico: IMDA, porcentaje de pesados y factor camion.
  2. Luego ajusta la estructura: espesores, soporte y parametros propios del tipo de pavimento.
  3. Presiona reproducir o mueve el tiempo para acumular ESAL con los anos.
  4. Observa la via: fisuras, ahuellamiento y baches aparecen cuando sube el dano.
  5. Compara las graficas: si el consumo llega a 100% o el PSI baja a 2.5, el pavimento falla.

Alcance tecnico

El simulador estima ESAL por trafico pesado y factor camion. La capacidad se aproxima con una curva tipo AASHTO 1993 usando numero estructural, modulo resiliente estimado desde CBR, serviciabilidad, confiabilidad y drenaje. Para carreteras aplica criterios del Manual MTC; para vias urbanas aplica CE.010 del RNE. Es una herramienta de apoyo, no reemplaza un diseno definitivo.

ESAL = IMDA x %pesados x Fv x 365 x Fd x Fc x crecimiento
